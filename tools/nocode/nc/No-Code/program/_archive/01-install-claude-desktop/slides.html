No-Code Lab · Lesson 01

Install Claude Desktop

A live walkthrough. We open the official page, download the app, and sign in together.

Why this lesson

This is the tool we will build with.

Claude Desktop lives on your computer. It can use your files, stay in the dock, and later connect to the tools in this program.

You will leave with

  • Claude Desktop installed on this Mac
  • The app opened from Applications
  • Your Claude account signed in
  • A first chat, so you know it works

What you need

Computer

A Mac on macOS 11 or later. This recording uses this machine.

Account

A Claude account. Free works for chat. Same email as claude.ai.

The five steps

  1. Open the official download page
  2. Download Claude for macOS
  3. Drag Claude into Applications
  4. Open the app (click Open if macOS asks)
  5. Sign in and send a first message

Live demo

We do this on the real website now.

Official page only: claude.com/download. No third-party installers.

After the demo

Checklist

  • Claude.dmg downloaded from Anthropic
  • Claude is in Applications
  • App opens without an error
  • You are signed in
  • A test message got a reply
