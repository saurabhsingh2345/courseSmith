# Why you don't need to learn to code

## The claim, said carefully
- "You don't need to learn to code" is true now in a way it was not in 2022.
- It is not the same as "code no longer matters" — the code still exists,
  still runs, and can still be wrong.
- What changed is who writes it, not whether it is written.
- Everything in this course rests on that distinction. If you skip it, the
  first time a tool fails you will think the tool is broken.

## The three jobs hiding inside "building software"
- Deciding what to build: what problem, for whom, and what it must do.
- Writing the code: turning that decision into instructions a computer follows.
- Keeping it running: hosting, data, accounts, fixing what breaks.
- People conflate all three under "coding", which is why "learn to code"
  sounded like the only door in.

## Only the middle one got automated
- Generative AI is very good at producing code from a clear description.
- It is not good at knowing which thing is worth building.
- It is improving fast at the third job and is not there yet.
- So the skill that matters now is describing precisely — which is a skill you
  already have some of, from every time you briefed anybody on anything.

## Who is actually doing this
- The majority of people using these tools are not developers: founders,
  product managers, designers, marketers.
- They are not building the next operating system. They are building the
  internal tool, the landing page, the booking form, the prototype that gets
  the meeting.
- That is not a lesser category. Most software that earns its keep is that.

## What you will have built by the end
- A real application, with a real database, that other people can open on the
  internet at an address you own.
- The habit of describing what you want precisely enough to get it.
- A clear sense of the edge — the point where you should stop and hire someone.

## The honest caveat, up front
- These tools cost money, and the cost is per-use, so it grows with your usage.
- They produce code you did not read. Sometimes that code is wrong in ways
  that only show up later.
- Anything touching payments, health data, or other people's private
  information deserves a professional's eyes before it goes live.
- Lesson twelve comes back to all of this properly. It is the most important
  lesson in the course and it is deliberately last.
