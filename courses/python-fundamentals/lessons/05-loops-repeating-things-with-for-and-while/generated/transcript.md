# Loops: Repeating things with for and while

## What are loops? [0:00]

Loops are a fundamental concept in programming. They help us repeat actions in our code. This means we can avoid writing the same code over and over again. Imagine having to print numbers from one to ten. Without loops, you'd have to write ten print statements! But with loops, we can do it in just a few lines. There are two main types of loops: for loops and while loops. Each has its own strengths and uses.


## Using for loops [0:32]

Now, let’s dive into for loops. For loops are great because they iterate over a sequence, like a list. They execute a block of code for each item in that sequence. ## Understanding while loops [1:03]

Next up, we have while loops. While loops repeat as long as a condition is true. This is really useful when we don’t know how many times we need to repeat something. For instance, we can use a while loop to count from zero to four. But we need to be careful! If we forget to update our condition, we might end up with an infinite loop. ## When to use each loop [1:34]

So, when should you use each type of loop? For loops are best when you know the number of iterations in advance. They’re straightforward and easy to read. On the other hand, while loops shine when you need to repeat something based on a condition. Choosing the right loop can really simplify your code and make it more efficient.
