# If and else: making decisions in code

## Understanding conditional statements [0:00]

Conditional statements are a key part of programming. They let us make decisions in our code. When we use them, we're evaluating conditions and executing code based on whether those conditions are true or false. The main types of conditional statements are 'if' and 'else'.


## The structure of if statements [0:17]

An if statement is the first step in making decisions. It checks a specific condition. If that condition is true, it runs the code block associated with it. If the condition is false, it simply skips that code block. For example, if we check if age is greater than or equal to 18, we can print a message saying, "You are an adult." Let's see that in action.


## Adding else statements [0:40]

Now, let’s talk about the else statement. This provides an alternative action when the if condition is false. By combining if and else, we can create two possible outcomes. For instance, if someone is under 18, we can print, "You are a minor." This way, we cover both scenarios.


## Using comparison operators [0:58]

Comparison operators are essential for defining our conditions. They help us compare values to see if they're true or false. Some common operators include equals, not equals, greater than, and less than. For example, if we check if the temperature is greater than 25, we can print, "It's a hot day."
