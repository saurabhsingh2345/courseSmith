# The print function: making Python say things on screen

## Introduction to the print function
- The print function displays output on the screen.
- It's one of the first things you'll use in Python.
- You can print text, numbers, and more.

## Basic usage of print
- You call print by writing print() with parentheses.
- Text should be enclosed in quotes inside the parentheses.
- Example: print('Hello, World!') displays 'Hello, World!'.

```python
print('Hello, World!')
```

```output
Hello, World!
```

## Printing multiple items
- You can print multiple items separated by commas.
- Each item will be displayed with a space in between.
- Example: print('Hello', 'World!') prints 'Hello World!'.

```python
print('Hello', 'World!')
```

```output
Hello World!
```

## Printing numbers and calculations
- The print function can also display numbers.
- You can print the results of calculations directly.
- Example: print(5 + 3) prints '8'.

```python
print(5 + 3)
```

```output
8
```

## Experimenting with print
- Try printing different types of data.
- Mix text and numbers in your print statements.
- Get creative with what you display on the screen.
