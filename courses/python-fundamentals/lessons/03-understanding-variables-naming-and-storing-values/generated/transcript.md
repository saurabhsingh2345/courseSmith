# Understanding variables: naming and storing values

## What is a variable? [0:00]

A variable is like a container for storing data values. It has a name that you use to reference the value stored inside. Variables can hold different types of data, like numbers or text. Let's look at that in a picture. Here, you can see how a variable has a name and a value. The name helps us identify what we're working with. And the value is the actual data we want to keep track of.


## Naming variables [0:24]

When naming variables, it's helpful to use descriptive names that reflect the value stored. You can start with a letter or an underscore, and then use letters, numbers, or underscores after that. Just remember, you can't use spaces or other special characters, except for underscores. This way, your variable names will be clear and easy to understand.


## Creating and storing values in variables [0:46]

You can create a variable using the assignment operator, which is the equals sign '='. For example, let's say we want to create a variable called 'my_variable' and store the value 10 in it. We write it like this: my_variable equals 10. Now, let's see how this looks in code. When we run this code, we can print the value of 'my_variable'. It shows us 10. This is how we store values in variables.


## Retrieving values from variables [1:12]

To use the value stored in a variable, you simply reference its name. For instance, if we have 'my_variable' set to 10, we can update it by adding 5 to it. We write: my_variable equals my_variable plus 5. When we print 'my_variable' again, it shows us 15. This way, you can see how easy it is to update values in variables.
