# Introduction to Python's basic data types

## What are data types?
- Data types define the kind of data we can use in Python.
- They help Python understand how to store and manipulate data.
- Common data types include strings, integers, floats, and booleans.

## Understanding strings
- Strings are sequences of characters, like words or sentences.
- They are enclosed in single or double quotes.
- You can concatenate strings using the '+' operator.

```python
print('Hello, ' + 'world!')
```

```output
Hello, world!
```

## Exploring integers and floats
- Integers are whole numbers, like 1, 2, or -5.
- Floats are decimal numbers, like 3.14 or -0.001.
- You can perform arithmetic operations with both types.

```python
print(5 + 3.2)
```

```output
8.2
```

## What are booleans?
- Booleans represent truth values: True or False.
- They are often used in conditions and comparisons.
- You can use booleans to control the flow of your program.

```python
print(3 > 2)
```

```output
True
```

## Overview of data types
- Let's summarize the basic data types in Python.
- Strings for text, integers for whole numbers, floats for decimals, and booleans for true/false.
- Understanding these types is essential for programming.
