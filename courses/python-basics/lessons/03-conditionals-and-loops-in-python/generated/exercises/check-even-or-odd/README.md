# Check Even or Odd

Write a function `check_even_or_odd(number)` that returns 'Even' if the number is even and 'Odd' if the number is odd. For example, `check_even_or_odd(4)` should return 'Even' and `check_even_or_odd(3)` should return 'Odd'.

Start from `starter.py`. The hidden tests in `test_exercise.py` must pass.
